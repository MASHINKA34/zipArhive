# Quick Zip

## Описание

Quick Zip — настольное приложение для Windows, которое собирает выбранные
файлы и папки в один ZIP-архив. Источник выбирается через диалог или
перетаскиванием прямо в окно: дерево можно раскрывать и отмечать нужные
файлы и каталоги галочками. Перед упаковкой видно количество выбранных
файлов и их суммарный размер. Имя архива по умолчанию подставляется из
названия выбранной папки.

Возможности:

- многопоточная упаковка: сжатие идёт на всех ядрах процессора;
- стандартное сжатие Deflate (уровень 6) без лишних настроек;
- уже сжатые форматы (jpg, mp4, zip, docx и т. п.) сохраняются без
  повторного сжатия, а неподатливые данные автоматически кладутся как есть;
- фоновое сканирование папок — окно не зависает даже на сотнях тысяч файлов;
- прогресс с процентами, скоростью и оценкой оставшегося времени, отмена
  на любом этапе;
- выбор папки и отметка нужных файлов и подпапок галочками в дереве;
- перетаскивание файлов и папок в окно, добавление нескольких источников;
- разные цветные значки для разных типов файлов;
- пустые папки сохраняются в архиве;
- «Показать в проводнике» открывает папку с архивом и выделяет его;
- сохранение настроек: размер окна, последняя папка;
- запуск с путями в аргументах: `QuickZip.exe C:\Data\Проект`;
- тёмная тема оформления.

## Требования

- Windows 10 или 11
- Python 3.11 или новее (проверено на 3.12)
- PyQt6

Все зависимости перечислены в файле requirements.txt.

## Установка

Рекомендуется использовать виртуальное окружение.

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt

Без виртуального окружения достаточно одной команды:

    pip install -r requirements.txt

## Запуск

Из корня проекта:

    python main.py

Можно сразу передать пути:

    python main.py C:\Data\Проект

## Горячие клавиши

| Клавиши            | Действие                       |
|--------------------|--------------------------------|
| Ctrl+O             | добавить папку                 |
| Ctrl+Shift+O       | добавить файлы                 |
| Ctrl+A / Ctrl+D    | отметить всё / снять отметки   |
| Delete             | убрать выделенное из списка    |
| F5                 | пересканировать источники      |
| Ctrl+Enter         | упаковать в ZIP                |
| Esc                | отменить сканирование/упаковку |

## Логи

Логи пишутся в `%LOCALAPPDATA%\QuickZip\logs\quickzip.log`
(ротация: 3 файла по 2 МБ), при запуске из исходников — ещё и в консоль.
Аварийные дампы падений процесса — в `crash.log` в той же папке.
Если окно перестаёт отвечать дольше 3 секунд, в лог пишется
предупреждение со стеком главного потока.

Уровень задаётся переменной окружения `LOG_LEVEL` (по умолчанию `INFO`):

    set LOG_LEVEL=DEBUG
    QuickZip.exe

## Тесты

    pip install -r requirements-dev.txt
    pytest

Тесты проверяют формат ZIP (чтение через стандартный `zipfile`, контроль
CRC, zip64, потоковые записи), сканер файловой системы, модель дерева и
сценарии окна целиком — сканирование, выбор, упаковку и отмену.

## Замер производительности

    python tools\benchmark.py --profile mixed

Скрипт генерирует набор данных, пакует его старым способом
(`zipfile.ZipFile.write`) и новым движком, после чего печатает время,
скорость и размер архива. Профили: `small`, `media`, `large`, `mixed`.

## Сборка в exe

Сборка одного исполняемого файла выполняется через PyInstaller:

    build.bat

После сборки исполняемый файл появится в папке dist:

    dist\QuickZip.exe

Параметры сборки описаны в QuickZip.spec: из дистрибутива исключены
неиспользуемые модули Qt (Quick, QML, PDF, мультимедиа, программный
OpenGL) и лишние переводы, поэтому файл заметно меньше стандартного.

## Как устроена упаковка

Файлы читаются и сжимаются пулом потоков (`zlib` освобождает GIL, поэтому
масштабирование идёт по числу ядер), а поток-писатель складывает готовые
блоки в архив строго в исходном порядке — результат не зависит от числа
потоков. Мелкие файлы группируются в пачки, чтобы не платить за
диспетчеризацию, большие делятся на блоки по 4 МБ и сжимаются параллельно
(блоки закрываются `Z_FULL_FLUSH`, CRC собирается через `crc32_combine`).
Расход памяти ограничен бюджетом в 192 МБ независимо от размера архива.
